# GCLP

GameCult Labor Platform. This repo holds only a `LICENSE` (MIT) and this file: it was created on 2 October 2020 and never received code. It is dormant.

The platform existed only as a design. The write-up is the `05.labor-platform` page of the archived `GameCult/gamecult-grav` repo (`pages/05.labor-platform/default.md`): a web app where members sign in with GitHub, browse and volunteer for outstanding issues across GameCult projects, and earn contribution points, backed by an application and database that talk to GitHub. That design is planned, not built here, and there is no successor implementation.

Nothing in this repo is runnable. For current GameCult work, start at `GameCult/gamecult-site` (the public site) or the org's repo list.
